Welche Verbesserung habt ihr gewählt, und warum diese?

Es hat gestört, dass die Kreise, welche die Einwohnerzahl der jeweiligen Städte visualisieren, sich teilweise mit den Ortsnamen überscheiden. Dadurch lassen sich die Ortsnamen schwerer lesen und es stört beim Schauen auf die Karte.


Woran habt ihr geprüft, ob sie stimmt? Hat es gestimmt?

Ich habe nachdem der Code verändert wurde geschaut ob die Kreise immernoch teilweise die Ortsnamen überschneiden. Zusätzlich habe ich die alte und neue Karte verglichen, um zu schauen, ob die Kreise noch ungefähr das gleiche Verhältnis zueinander haben. Beides hat gestimmt.


Spezifikation:

Im Code soll die Funktion die den Radius der Kreise bestimmt so verändert werden, dass die Kreise sich nichtmehr mit den Ortsnamen überschneiden. Wichtig ist, dass die Größen der Kreise immer noch korrekt die Einwohnerzahl der Städte visualisieren.
